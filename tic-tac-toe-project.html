Tic-Tac-Toe

Interactive JavaScript Game

A browser-based Tic-Tac-Toe game built to practice JavaScript fundamentals, interactive user interfaces, and responsive front-end development.

View Live Site ↗ View Code ↗
01 / THE PROJECT

Project Overview.

Tic-Tac-Toe is an interactive browser game created as a front-end development project to strengthen my JavaScript programming skills.

The game allows players to take turns placing X and O on a grid, with JavaScript handling the game state, player turns, and winning conditions.

02 / MY CONTRIBUTION

My Role.

I developed the game interface using HTML and CSS and implemented the interactive functionality using JavaScript.

My work focused on handling player interactions, updating the game board, checking for winning combinations, and providing a way to restart the game.

03 / REFLECTION

What I Learned.

This project helped me better understand JavaScript event listeners, conditional logic, arrays, and DOM manipulation.

I also gained experience breaking down a larger problem into smaller functions, testing game behaviour, and creating a responsive, interactive user experience.
